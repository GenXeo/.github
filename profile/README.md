# GenXEO

GenXEO is the SEO/AEO technical analysis engine and discoverability module in the IndexMesh ecosystem.

It supports website crawling, schema extraction, technical SEO checks, AEO readiness analysis, entity consistency review, authority signal checks, and report narrative generation for the Index Mesh Score and future GenXEO module.

## Current Status

This organization is a reserved namespace for the GenXEO brand. Active development currently happens under the primary IndexMesh organization.
